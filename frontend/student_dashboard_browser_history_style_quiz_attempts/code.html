In the 0/1 Knapsack problem with capacity W and items with weights w_i and values v_i, what is the optimal state transition when considering item i with subproblem capacity j < w_i?

close
Your Answer: dp[i][j] = max(dp[i-1][j], dp[i-1][j - w_i] + v_i)
check
Correct Formulation: dp[i][j] = dp[i-1][j] Item cannot fit since its weight exceeds current capacity j.
psychology
Instructor & AI Algorithmic Explanation

When the current item's weight w_i exceeds the remaining subproblem capacity j, you strictly cannot include item i. Therefore, the maximum attainable value is inherited from excluding item i: dp[i][j] = dp[i-1][j]. Attempting to subtract w_i when j < w_i triggers a negative index boundary error.
